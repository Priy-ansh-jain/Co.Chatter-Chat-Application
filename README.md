Co.Chatter is a real-time chat application where users can register, log in, join chat rooms, and send instant messages to each other. It uses React for the frontend, Node.js/Express for the backend, Socket.IO for real-time messaging, and MongoDB for the database.

How i setup this application 
> Use Vite with React
> For CSS i have used "Tailwind" and "ShadCN"
> For backend "node JS" and "Express" with "mongoose".
>Socket Io for real-time
🚀 Features

👥 User Authentication (Register & Login)
💬 Real-time chatting with Socket.IO
📦 Fully separated frontend and backend
🌐 REST API with secure JWT tokens
📱 Responsive UI (built with Tailwind CSS)
